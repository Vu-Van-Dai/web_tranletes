# Advertising layout rollout

Deploy backend and frontend together. No database migration; optional fields are stored in existing settings JSON. After deploy, Admin > Quảng cáo > Sắp xếp Adsterra theo kích thước > inspect draft > Lưu thay đổi. The preset never enables or approves a unit. Side rails are fixed on viewports at least 1700 CSS pixels and are not rendered on reader pages. One weighted candidate per slot; separate approved async tags may coexist, but the existing direct IFRAME SYNC cap remains one per document. Ask Adsterra for supported JSAsync tags for additional fixed-size placements; never simulate tracking or override document.write. The browser diagnostic reports visible element heuristics, not a verified fill/impression. The script cap limits injection, not vendor-controlled behavior. Both direct and isolated HTML banners collapse when the bounded element check fails. Cross-origin vendor frames can still be empty internally, so this is best effort, not guaranteed no-fill detection. Smartlinks are explicit labeled links only. Keep ads lawful and age-appropriate; review categories with providers. No R2, image Worker, SEO, package, or payout changes.

Revenue API follow-up: official Adsterra publisher API https://adsterra.com/api/ ; HilltopAds https://hilltopads.com/publishers/api ; Clickadu https://faq.clickadu.com/en/articles/6234995-api-integration-guide . Use scoped publisher credentials in server secrets only, filter to approved website/zone IDs, map date/currency, upsert monthly reports. No credentials or automatic sync configured in this PR; existing manual reports remain authoritative.
