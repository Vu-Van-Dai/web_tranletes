# Ad runtime compatibility follow-up

Frontend-only change. Keep public CSP, sandbox, R2/Worker, SEO and API untouched. Existing config is not modified until an administrator explicitly saves it. In Admin > Quảng cáo, choose the layout preset, inspect, save. For testing popunder use the new draft preset, review provider categories and separately approve/enable the official popunder tag. It disables Adsterra Smartlink and Social Bar in the draft only. Adsterra recommends avoiding Smartlink on navigation controls: https://adsterra.com/smartlink-ads/ . Do not click own ads, do not attach paid links to unrelated clicks. Use official Popunder for vendor-controlled clickunder behavior with clear notice, frequency caps and lawful general-audience ads. The shared cap controls network script injections only, minimum 1 minute per selected unit, not vendor opens; browser storage may be unavailable.

Async recognition supports external HTTPS async tags with optional independent atAsyncOptions.push setup, not arbitrary inline global configs. Sync cap remains. Never synthesize tags, modify provider tracking, enable unsafe-eval or share account cookies. Obtain official JSAsync for fixed sizes from provider; verify actual tag shape. Each placement needs distinct source/container. Protocol-relative HTTPS URLs normalize to HTTPS. Fallback is only an already configured direct image+link in the same eligible slot, not another paid network or automatic reload. Diagnostics are local and heuristic; cross-origin empty iframes cannot be inspected. Test synthetic tags in CI and real display on production after merge. No credentials or revenue API changes.

## Publisher-provided tag placement

The supplied Popunder single-script family (abscloud.org /1/) is appended directly to document.head; the Social Bar family (bauval.org /14/) is appended directly to document.body. Existing approval, guest-only and frequency checks remain. Exact tag attributes are preserved; the dynamic script is inserted only after public eligibility is established, so this is not parser-time insertion and must be confirmed in production/provider guidance. All six bauval.org /22/ fixed-size tags supplied by the publisher are IFRAME SYNC with global atOptions. They remain capped at one directly mounted sync tag per document until official alternative tags are supplied. The native /21/ tag is async. No live ad requests or publisher key changes are made. Adsterra also advises using distinct tags rather than duplicating the same banner: https://adsterra.com/blog/how-banner-ads-make-money/ .
