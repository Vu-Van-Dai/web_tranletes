# Frontend / Cloudflare Pages SEO rollout

No backend or database migration. The image delivery Worker is intentionally unchanged (it serves img.rongnho.shop, not public HTML).

- Cloudflare Pages Functions serve a lightweight server-generated HTML representation to every visitor on public catalog routes. React still replaces it on startup; this is not full React SSR. Existing API routes, reader packages, accounts, and database IDs are unchanged.
- Detail URLs keep UUID + slug until backend can enforce globally unique slugs or implement a house-qualified lookup. Old or incorrect slugs redirect to the correct existing URL. Missing public resources return 404; temporary upstream failures return 503, never a permanent noindex. Search/account pages are noindex; mature chapter readers are deliberately noindex and do not expose chapter images in the edge HTML.
- Existing sitemap proxy remains unchanged. Chapter/genre/house sitemap expansion, stable lastmod, slug migration, structured data and provider persistence wait for backend work or a separate reviewed change.
- AdSense ownership meta tag remains when PUBLIC_ADSENSE_CLIENT is set. Auto ads are opt-in with PUBLIC_ADSENSE_AUTO_ADS=true and limited to non-mature comic details when the site ad switch is on. Keep it disabled until approved. When AdSense Auto ads is opted in, third-party placements are disabled across the deployment to avoid mixing incompatible ad formats. Existing third-party provider settings remain in the existing API; no new ad provider is activated. Existing direct scripts still require trusted publishers and category controls; a reload on navigation/disable discards their registered listeners. Admin/auth/info/search and mature detail/reader routes are ad-free. The public site setting is refreshed every 60 seconds, subject to API caching.
- Cloudflare Pages root directory frontend, command npm ci && npm run build, output dist. PUBLIC_API_URL should be https://api.rongnho.shop in build and runtime; edge uses that as default. The _routes.json file keeps asset requests out of Pages Functions.
- Before production: npm ci, npm run typecheck, npm test, npm run build in frontend. Deploy preview, verify view-source/HTTP GET and HEAD, correct canonical/301/404/503, sitemap and workspace access, reader navigation, and ad switch. Check Search Console live URL test before requesting indexing. Do not re-submit AdSense until rights, policies and content are reviewed.
